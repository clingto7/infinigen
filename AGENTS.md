## Agent skills

### Issue tracker

Issues and specs live in GitHub Issues for `clingto7/infinigen`. See `docs/agents/issue-tracker.md`.

### Triage labels

Use the five default triage labels. See `docs/agents/triage-labels.md`.

### Domain docs

Use the single-context layout: root `CONTEXT.md` and `docs/adr/`. See `docs/agents/domain.md`.

### Spraybot workpiece interfaces

When adding or changing a registered workpiece generator, face-field policy, parametric export, trajectory program, machine gate, or interface/trajectory review evidence, follow `.agents/skills/spraybot-interface/SKILL.md`. It routes to the project workflow and the relevant contracts before implementation or publication.
