# 按几何类型扩展统一参数化描述契约

下游应仅凭导出包和说明编写跨种子运行的轨迹程序，因此采用统一的描述契约，固定单位、坐标、部件实例、曲面域、网格对应和近似误差等公共含义，并按几何类型提供明确的求点与法向定义。描述生成优先在共享几何构造原语处提取实际参数，以跨工件复用，避免为每个工件维护一套下游必须另读源码的参数字典。

统一契约不意味着所有几何共用一组可选字段，也不意味着当前已能描述任意部件。首批矩形平面、圆柱侧面和圆盘已形成 `spraybot.parametric.v1`；三角形平面新增于 `v2`。契约见 `docs/spraybot/parametric-description-contract.md`；未知类型必须显式报错或标记未支持，不能静默丢弃或伪装为已支持类型。Bézier 扫掠、裁剪曲面及其他表达的具体结构继续验证，扩展时使用明确的新版本。

连续参数曲面与离散网格的差异应明确记录来源和误差范围。网格离散误差、路径采样误差与未来可能出现的拟合误差不能混作工艺容限；本项目不依据未知喷枪或涂层要求宣称这些误差可接受。

验收分别记录消费程序是否正确理解描述，以及源几何与描述是否有效一致。扫掠局部折返、退化或法向反转等问题不能因消费程序成功运行而放行；经过顶点合并等拓扑操作时，原始构造面来源与实际曲面片的网格支持范围也应明确区分。
