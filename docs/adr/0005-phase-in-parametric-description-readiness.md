# Phase in parametric descriptions for every workpiece interface

Every generator exposed through the `Workpieces` or legacy `Spraybot` workpiece registry, and every future workpiece interface, is in scope for a generation-time parametric description. An interface is **parametric-description ready** only when all `spray_target` faces have evaluable surface points and outward normals, map to the final mesh, and pass multi-seed consistency checks; any undescribed non-target faces remain explicit. Apply this delivery gate to new interfaces immediately: they may register for development and validation, but cannot be marked ready for production until it passes. The batch worker tries the same capture path for every registered `workpiece:` interface, writes complete uncertified descriptions as candidates, and records incomplete mappings without disabling model generation. The certified readiness manifest is separate from the worker implementation, so scaling to a new interface means adding shared primitive adapters and evidence, then recording the certified entry. Existing interfaces are the near-term priority; no new-interface expansion is planned before the parametric workflow is established. This keeps one eventual standard while avoiding a disruptive retroactive shutdown of the current library.
