# 工件参数化表示独立于喷枪和工艺

上游工件生成阶段无法预知下游的喷枪尺寸和喷涂工艺，因此参数化表示描述工件本身的几何与部件关系，不以某一种喷枪或工艺决定几何细节的取舍。允许将参考物体的曲线拟合为 Bézier 等参数曲线，但应保留主要部件、截面、连接关系和间隙，并显式记录几何近似误差及省略细节；纹理与颜色不属于本阶段的重建目标，这不取消已有的材质与喷涂目标面语义。

接口通过依据导出模型和描述数据编写的轨迹程序进行多种子抽样验证；这用于检验描述是否充分且一致，不构成对未知喷枪和工艺的通用可执行性保证。批量轨迹数据生产仍由 Spraybot 负责。

下游轨迹程序应仅依赖导出包和接口说明，无需读取 Infinigen 生成源码。验收使用固定程序处理开发样例以外的种子，检查表面路径、目标面对应和法向；机器人可执行性及实际涂层质量不属于本项目的验收结论。
