# Preserve native Spraybot generator variation

Integrate `CarBumper`, `OpusChair`, and Infinigen `ChairFactory` as the
independent `car_bumper`, `opus_chair`, and `infinigen_chair` interfaces while
preserving their source-native structural branch variation. This is a one-time
compatibility exception for these Spraybot-native generators; the general
workpiece category rule to lock structural branches remains unchanged. Review
20 seeded instances and their face-data visualizations before accepting the
resulting interfaces.
