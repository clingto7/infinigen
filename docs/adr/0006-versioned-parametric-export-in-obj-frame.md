# Export a separate versioned parametric artifact in the OBJ frame

Each parametric-description-ready production episode adds `parametric.json`, referenced by `metadata.json`, alongside the existing OBJ, `structure.json`, and `face_attributes.npz`. Episodes from interfaces still awaiting retrofit retain their existing files and an explicit incomplete status; they must not claim parametric readiness. The new artifact's schema is independently versioned; existing construction records and native priors in `structure.json` keep their meanings. Public surface evaluation returns points and outward normals in the exported OBJ's axes and origin, with points in meters. The OBJ remains in millimeters, so the artifact states the conversion explicitly; face references use the OBJ triangle order shared with `face_attributes.npz`. A separate artifact avoids reinterpreting `spraybot.generation-data.v1` while giving downstream coding agents a stable, process-independent description.
