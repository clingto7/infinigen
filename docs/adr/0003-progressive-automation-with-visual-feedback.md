# 通过可视化反馈逐步实现参数化自动化

参考三维物体的参数化以整个环节最终自动化为目标，第一阶段允许系统生成候选后，由人确认部件划分、连接关系和拟合等不确定结果，再自动生成工件并进行多种子验证。选择该路线是为了在判断能力尚未验证时保留纠错入口；人工确认是阶段性措施，不作为最终流程的必需环节。

复用现有 `scripts/spraybot_generator_ui_server.py` 对应的 Web 界面，逐步承载模型及描述数据的检查、反馈和迭代。后续设计需明确反馈如何关联到具体候选和版本，以及如何用于修正；这些机制尚未确定。

本项目的模型输入仅来自 Infinigen 生成接口，不考虑外部模型导入、真实扫描点云或残缺结构补全。允许自动化程序读取现有生成代码，利用构造过程提取实际几何参数，并将导出描述与生成网格进行一致性验证；自动化目标限定为这一有生成源码的流程。
