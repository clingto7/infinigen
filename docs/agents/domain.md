# Domain docs

This is a single-context repo. Read root `CONTEXT.md` before exploring
Spraybot workpiece categories, generators, or data interfaces. Read
relevant decisions in `docs/adr/` when that directory exists.

Use the glossary's terms in issues, proposals, hypotheses, and tests.
In particular, do not count generator names or size variants as
workpiece categories. If a needed term is missing, revisit the domain
model. Surface conflicts with an existing ADR explicitly.

Missing ADRs do not require creating a document in advance; add one
when a consequential decision is actually made.
